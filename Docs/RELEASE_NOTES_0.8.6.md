# OKVideoMac 0.8.6（Build 139）Release Notes

- 官方 DMG 配置崩溃报告接收服务。默认不上传；用户在恢复页或设置中明确同意后，才发送过滤后的诊断报告。可关闭上传并清理未发送报告与缓存；已发送报告不能从本机撤回。
- 公开源码保留完整捕获、恢复和上传实现，实际接收地址默认留空。正式打包从仓库外的私有文件注入公开 HTTPS DSN，不向源码归档或打包日志写入地址；后台管理令牌不进入 App。
- 未配置服务的源码构建明确显示“上传未配置”，禁止开启无法发送的开关，同时仍可关闭已有授权和清理待发送报告。
- 正式打包在缺失或无效配置时停止；新增源码归档地址隔离、私有文件权限与 Sentry 管理令牌扫描检查。
- 继承 0.8.5 的本机恢复、窗口重开、有限 SDK 检查与弹幕文字填充/Retina 阴影改进。感谢 PR #9 的原作者贡献。

报告只包含版本、系统、架构、错误码、线程地址与模块 UUID 等诊断字段，不包含播放内容、配置、账号、凭据、日志或原始崩溃文件。接收地址是可从 App 读取的公开客户端配置，不赋予读取后台报告或管理账号的权限；实际管理凭据只在构建环境使用。

正式版须完成 Release 测试、匹配 dSYM、合成事件后台解析、Developer ID、Apple 公证、staple、Gatekeeper、安装与公开资产验证后发布。实际结果及未测范围见发布后的正式验证记录。既有 0.8.5 tag 与资产保持不可变。
